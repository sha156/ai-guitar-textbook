# 吉他教学大纲精排版 — 制作计划

> 2026-07-20。任务：把《吉他课程教学大纲_第1-35课_第一至第三阶段详化版.pdf》用 XeLaTeX 重排成
> 出版物级 PDF。**内容零改动**——所有课程文字以 `build\content_extracted.txt` 为唯一真源，
> 只升级排版、配图与视觉系统；新增的结构页（路线图、曲库表等）只重组既有信息，不编造数字。

## 一、设计系统

- **配色：深蓝典藏**。主色 #1B2A4A 墨藏青；四阶段色：一 #2E86AB 晴空蓝 / 二 #0F8B8D 青碧 /
  三 #C89B3C 黄铜金 / 四 #A63A50 酒红；正文 #3C4048 墨灰。全书颜色只在导言区定义一次。
- **字体**：中文正文宋体（ctex windows fontset）+ 标题 Microsoft YaHei；西文正文 Palatino Linotype，
  西文无衬线 Segoe UI。全书 ≤3 字族。
- **页面家具**：随阶段变色的满宽页眉色条（左阶段名/右课程范围）+ 阶段色圆形页码；
  `\SetStage` 状态宏统一驱动页眉、卡片、列表符号换色。
- **课程卡片**：tcolorbox 悬浮标题条 + 反白课号徽章 + 「教学目标/教学内容/课堂练习」三个图标子块 +
  选曲徽章行（仅有选曲的课出现）。35 课全部走同一个环境，版式零漂移。

## 二、文档结构（页序）

1. **封面**：TikZ 满版深蓝 + 音孔同心圆 + 琴弦线 + 底部金带。标题沿用原文：
   吉他课程教学大纲｜第 1-35 课·第一至第三阶段详化版。
2. **整理说明 + 使用说明**：原文整理说明原样保留；新增四阶段颜色图例与卡片结构说明（纯导读）。
3. **全书课程路线图**：四纵列 roadmap，35 课真实课名药丸 + 阶段色列头 + 进阶箭头，一页 A4。
4. **四个阶段扉页**：整页阶段色 + 超大阶段号水印 + 阶段名（原文真实名）+ 本阶段课程列表半透明卡。
5. **35 张课程卡片**：每课三层结构文字逐字来自原文；选曲/曲目练习/长期作业/结课曲目做成徽章行。
   第四阶段 31-35 课原文仅有标题——照实排为标题卡，并保留原文「后续再逐课细化」的说明。
6. **附录 A 曲库总表**：课号/曲目/出现方式/绑定课题，全部来自原文。
7. **附录 B 图片来源与授权**：Wikimedia 图逐张列作者与许可证（CC BY / CC BY-SA 要求署名）。
8. **封底**：舞台演出图 + 深蓝收尾。

## 四、工程与验收

- 工程：`build\tex\`（main.tex + guitar-macros.sty + stage1-4.tex + frontmatter/appendix.tex），
  图片 `build\images\`（wiki/ 与 ai/ 子目录）。
- 编译：`xelatex -interaction=nonstopmode` **两遍**（remember picture 对位）；latexmk 缺 perl 不用。
- QA（假修复防线）：pdftoppm 渲染全 PDF 为 PNG **逐页目检**——检查溢出、错位、图文重叠、
  字体缺失、页眉换色是否正确；批量对账：35 课卡片数、图片引用数逐一核对。
- 交付：`D:\Project\py\bcq\吉他课程教学大纲_第1-35课_精排版.pdf`，并更新 CHECKPOINT.md。
